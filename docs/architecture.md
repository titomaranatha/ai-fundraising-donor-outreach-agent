# Architecture

| Stage | Function |
|---|---|
| Discovery | Finds donors, NGOs, foundations, philanthropists, CSR programmes |
| Research | Identifies relevant causes and funding priorities |
| Extraction | Pulls sponsorship and grant opportunities |
| Qualification | Scores and prioritises prospects |
| Generation | Drafts personalised emails |
| Review | Prepares drafts for approval |
| Approval gate | Owner approves, edits, or rejects |
| Delivery | Sends only approved emails |
| Tracking | Records sends and responses |
| Follow-up | Manages follow-ups and outreach records |

Whether these stages are separate agents or one agent with multiple steps is **unverified**.
